# Project 3 - Visualize

## Project Overview
The Federal Highway Administration, also known as FHWA, have requested that we analyze two highly influential data sets. The first is the National Household Travel Survey, and the second is the Next Generation Simulation data. These two data sets provide useful insight into transportation usage trends & driving behaviors. To further explore our datasets, we will utilize the Intelligent Driver Model for simulations. We will visualize data using Python to create bar graphs, histograms, boxplots, & time-series.
